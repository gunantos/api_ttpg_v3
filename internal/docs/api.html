Dokumentasi API TTPG

Terminal Tiket & Gate + modul Penginapan. 4 MySQL (ttpg_users, ttpg_auth, ttpg, ttpg_penginapan) + MongoDB (ttpg). Semua endpoint, parameter, body, dan contoh respons ada di bawah — lengkap dengan snippet cURL, PHP, Python, Node.js, dan Go.

Halaman ini disajikan langsung oleh server (public, tanpa auth) di /docs. Token & API key di toolbar hanya dipakai browser Anda (localStorage) untuk fitur Coba — tidak dikirim ke mana pun selain Base URL di atas.

Ringkasan Auth

CaraHeaderDipakai untuk
Tanpa auth—POST /auth, /boarding/print/:code, /penginapan/payments/:id/receipt, /penginapan/webhooks/{midtrans,xendit}, /ws, /docs, /activity
JWTAuthorization: Bearer <token>semua route protected — token dari POST /auth, berlaku 1 minggu
BasicAuthorization: Basic base64(user:pass)semua route protected — user aktif di ttpg_users.user (bcrypt)
API key userX-ttpg-key: dev-key-123 atau X-API-Keysemua route protected — cocok user.secret_key di ttpg_users
API key literalX-ttpg-key: 12345 atau X-API-Keysemua route protected — cocok literal dengan env API_KEY (superkey, user_id=0)
Satu middleware seragam (auth.AuthMiddleware): header API key (literal env API_KEY dulu, baru user.secret_key) → Authorization (Bearer/Basic). Digest dilepas. Lalu aturan endpoint dari tabel api_url/access (skema wajib + izin) — ditolak → 403. Gagal auth → 401 + WWW-Authenticate (Basic). Semua request dicatat async ke logs (query + body ter-redaksi, password/secret/token → [REDACTED]) dan dihapus otomatis lebih tua dari LOG_RETENTION_DAYS (default 30 hari) — lihat halaman /activity.
